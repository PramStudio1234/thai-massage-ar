เว็บแอปพลิเคชันสำหรับการฝึกทักษะหัตถศาสตร์นวดแผนไทยตามแนวเส้นประธานสิบและจุดกายวิภาค โดยผสานเทคโนโลยีตรวจจับโครงสร้างร่างกายและมือด้วย **MediaPipe (Pose & Hand Tracking)** แบบเรียลไทม์ พร้อมการแสดงผลจำลองอินฟราเรด (Infrared Style Filter), เส้นเลเซอร์เชื่อมต่อ (Visual Connection Beam), โลจิกหยุดเวลาอัจฉริยะเมื่อมือหลุด (Smart Pause/Resume Timer), และระบบประเมินคะแนนเชิงลึกด้วย AI (AI Clinical Insights Engine)

## 🚀 ฟีเจอร์หลักของระบบ (Feature Overview)

### 1. ระบบยืนยันตัวตนและการเข้าถึง (Authentication & Role Routing)
* **ลงทะเบียน (Register)**:
  * กรอกข้อมูล: ชื่อ-นามสกุล, เบอร์โทรศัพท์, อีเมล, วันเดือนปีเกิด และเลือกบทบาทที่ต้องการขอสิทธิ์ (User หรือ Admin)
  * **Real-time Password Validation**: ระบบตรวจสอบการพิมพ์ตรงกันของ "รหัสผ่าน" และ "ยืนยันรหัสผ่าน" แบบเรียลไทม์ หากไม่ตรงจะแสดงข้อความสีแดงเตือนทันที (`"รหัสผ่านไม่ตรงกัน กรุณาระบุให้ถูกต้อง"`) และล็อคปุ่มส่งข้อมูลจนกว่าจะพิมพ์ตรงกัน
* **เข้าสู่ระบบ (Login)**:
  * ใช้อีเมลหรือรหัสนักศึกษา พร้อมรหัสผ่าน
  * **⚡ 1-Click Demo Login**: ปุ่มทางลัดสำหรับทดสอบสิทธิ์ User, Admin และ Super Admin ได้ทันทีโดยไม่ต้องจำรหัสผ่าน
* **Role Routing**: ระบบจะตรวจเช็ค Role ของผู้ใช้งานและเด้งไปยังหน้า Dashboard ที่ถูกต้องโดยอัตโนมัติ

### 2. โมดูลผู้เรียน (User Module)
* **2.1 หน้า Dashboard (Welcome Screen)**:
  * ข้อความต้อนรับ: *"ยินดีต้อนรับเข้าสู่ระบบ Thai AR-Massage Wellness"*
  * ปุ่ม *"คลิกเพื่อดำเนินการต่อ"* นำทางเข้าสู่เมนูเลือกจุดนวดกายวิภาค
  * **หมวดหมู่จุดนวด (3 Body Sections)**:
    1. **ร่างกายท่อนบน (Upper Body)**: คอ (ท้ายทอย, กระดูกคอ), บ่า (ยอดบ่าซ้าย-ขวา), ไหล่, ขมับ (จุดไท่หยาง)
    2. **ร่างกายท่อนกลาง (Middle Body)**: แขนบน (แนวเส้นประธานแขน), แขนล่าง (แนวพังผืดข้อมือ)
    3. **ร่างกายท่อนล่าง (Lower Body)**: น่อง (แนวเอ็นร้อยหวาย), ต้นขา (กล้ามเนื้อหน้าขา), เข่า (รอบสะบ้าเข่า, ตานกพิราบ)
  * **เงื่อนไข UI**: เมื่อเลือกหมวดใดหมวดหนึ่ง ระบบจะโหลดจุดเป้าหมาย (Target Nodes) ขึ้นมาบนจอ AR เฉพาะหมวดนั้น เพื่อลดความสับสนของผู้เรียน
* **2.2 หน้าจอฝึกปฏิบัติจริง (AR Massage Simulation)**:
  * **Camera View**: เปิดกล้องหน้า (Webcam) พร้อมฟังก์ชันสลับฟิลเตอร์จำลองภาพความร้อนอินฟราเรด (**Infrared / Thermal Style Filter**) และ Holographic Cyber AR
  * **Target Visualization (วงกลมสีแดง & ลูกศรชี้นำทิศทาง)**:
    * วงกลมสีแดงแสดงบนตำแหน่งกายวิภาคที่ต้องนวด
    * **ลูกศรชี้นำทิศทาง 3 รูปแบบ**:
      * 🌀 **ลูกศรวงกลม**: นวดคลึงวน (Circular Kneading) หมุนวนแบบอะนิเมชัน
      * ↕️ **ลูกศรขึ้นลง**: นวดรีดเส้นตามแนวกล้ามเนื้อ (Up-Down Linear Strokes) ขยับเลื่อนขึ้นลงตามมัดกล้ามเนื้อ
      * 🎯 **ลูกศรรูปคลื่น/วูบวาบ**: นวดกดจุด (Pressing/Pulsing) คลื่นความถี่วูบวาบขยายตัว
  * **Information Panel (แผงข้อมูลด้านข้าง)**:
    * แสดงชื่อตำแหน่งเป้าหมายปัจจุบัน (ภาษาไทยและภาษาอังกฤษ)
    * คำแนะนำเชิงหัตถการ เช่น *"แนะนำ: นวดคลึงวนเป็นวงกลม"*, *"แนะนำ: รีดขึ้นลงตามแนวกล้ามเนื้อ"*, *"แนะนำ: กดจุดค้างไว้และปล่อย"*
    * แสดงจำนวนมือที่โฟกัส วงสีส้ม เส้นโครงมือสีฟ้า รอยการเคลื่อน และสถานะทิศทาง/เวลาที่เหลือ
* **2.3 โลจิกการจับเวลาและการตรวจจับ (Tracking Logic & Timer)**:
  * ตรวจจับมือด้วย **MediaPipe Hand Tracking** (ปลายนิ้วและฝ่ามือ)
  * **Hand Focus**: ค่าเริ่มต้น 1 มือ ติดตามมือเดิมและไม่ใช้มืออีกข้างตัดสินเวลา เลือก 2 มือเพื่อตรวจทั้งคู่แยกกัน มีปุ่มเลือกมือใหม่โดยคงเวลาที่สะสม
  * **Active State**: ยอมให้ฝึกปฏิบัติทีละ 1 จุดอย่างแม่นยำ
  * **Strict Timer Logic**:
    * เริ่มนับเมื่อมือที่โฟกัสผ่านทิศทางตามลูกศร ไม่ตรวจระยะจากจุดนวดหรือบังคับรัศมี โหมด 2 มือใช้สถานะที่ผ่านของทั้งคู่
    * **Pause/Error Condition**: หยุดเมื่อไม่พบมือที่โฟกัส พบการเคลื่อนผิดทิศ กด Pause หรือกำลังปรับจุด หลังทิศทางผ่าน มือที่ตรวจพบและหยุดนิ่งยังคงสถานะที่ผ่านตามเงื่อนไขล่าสุด
    * **Guide Colors**: จุดนวดสีแดงโปร่งแสงขนาดเล็ก จุดสำเร็จสีเขียว และวงติดตามมือสีส้มพร้อมหมายเลขแยกแต่ละมือ
    * เมื่อเปลี่ยนเป็นสีเขียว ระบบจะส่งเสียงเฉลิมฉลองและเลื่อนไปยังจุดถัดไปโดยอัตโนมัติ
* **2.4 แผงควบคุมระหว่างฝึก (In-Game Controls)**:
  * ปุ่ม "หยุดชั่วคราว (Pause)" / "เล่นต่อ (Resume)"
  * ปุ่ม "เริ่มใหม่ (Reset/Retry)" ล้างค่าด่านปัจจุบันและเริ่มนับเวลาใหม่
  * ปุ่ม "กลับหน้าแรก (Home)"
  * ปุ่ม "เปิดมือจำลอง (Virtual Hand Mode)" สำหรับทดสอบระบบได้ทันทีแม้ไม่มีกล้องเว็บแคม
* **2.5 การให้คะแนนและสรุปผลด้วย AI (Post-Session AI Feedback)**:
  * Pop-up แสดงคะแนนเต็ม **100%**:
    * **ความต่อเนื่อง (Continuity - 40%)**: คำนวณจากจำนวนครั้งที่การตรวจจับมือที่โฟกัสขาดช่วง
    * **ความถูกต้องของทิศทาง (Directional Accuracy - 40%)**: ตรวจจับความแม่นยำของเวกเตอร์การขยับมือ
    * **ความสม่ำเสมอของความเร็ว (Efficiency - 20%)**: คำนวณจากการกระจายของความเร็วและการเคลื่อนเร็วเกินเกณฑ์ สูตรปัจจุบันไม่ได้คำนวณจากการฝึกครบเวลาเพียงอย่างเดียว
  * **AI Recommendation**: ข้อความรีวิวทางการแพทย์ภาษาไทย เช่น:
    > *"คุณทำได้ดีมากในจุดบ่า แต่ตอนนวดขมับมีการหมุนผิดด้าน (หมุนซ้ายแทนที่จะหมุนขวา) คำแนะนำ: พยายามรักษาระดับมือให้คงที่เพื่อลดการหลุดของเซนเซอร์ระหว่างการกดจุด"*
  * รองรับการเชื่อมต่อกับ **Google Gemini API** เพื่อสร้างคำแนะนำแบบสด

### 3. โมดูลผู้สอน/ผู้ประเมิน (Admin Module)
* **Role Approval System**: แสดงคำขอสมัครสมาชิกที่รอการอนุมัติ สามารถกด **"อนุมัติ (Approve)"** หรือ **"ปฏิเสธ/เตะออก (Reject/Kick)"** โดยแยกหมวดคำขอ User และ Admin
* **Simulation Mode**: ปุ่ม **"จำลองการเป็นผู้ใช้"** เพื่อให้อาจารย์เข้าไปทดสอบระบบ AR Massage ได้เสมือนจริงทันที
* **User Dashboard & Analytics**:
  * ค้นหาและดูรายชื่อนักศึกษาทั้งหมด
  * **Individual Stats**: จำนวนรอบที่ฝึก, ตารางประวัติคะแนนย้อนหลังแต่ละรอบ
  * **Trend Line Graph**: กราฟแสดงเส้นพัฒนาการของคะแนนในแต่ละครั้งที่ฝึก
  * **Overall AI Insights**: AI สรุปรายงานภาพรวมของนักศึกษาคนนั้นให้อาจารย์ทราบ เช่น จุดแข็งการรีดเส้น และจุดที่ต้องแก้ไขเรื่องการนวดคลึงวน

---

### 4. โมดูลนักพัฒนา/ไอที (Super Admin Module)
* **Terminal UI & System Logs**: หน้าต่างคำสั่ง CLI จำลองสำหรับ Developer (`help`, `status`, `users`, `nodes`, `db:stats`, `db:reset`, `ping`, `clear`)
* **Module Configuration**:
  * เพิ่มจุดนวดใหม่ (Add Target Node) ระบุชื่อ TH/EN, หมวด, ท่าทาง, พิกัด X/Y, และเวลา
  * แก้ไขหรือลบจุดนวดเดิม
  * **ปรับจูน MediaPipe Hitbox Radius**: สไลเดอร์ปรับรัศมีความยากง่าย (30px - 100px) และความไวเซนเซอร์ได้แบบสดๆ
* **Global Override & Database Access**:
  * แก้ไขบทบาท (Role) ของผู้ใช้งานทุกคน
  * ลบผู้ใช้งาน หรือรีเซ็ตฐานข้อมูลทั้งหมดกลับสู่ค่าเริ่มต้น

## 💻 วิธีการเปิดใช้งาน (How to Run)

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์ `start.bat`
เพียงดับเบิ้ลคลิกที่ไฟล์ **`start.bat`** ในโฟลเดอร์ ระบบจะเปิดเบราว์เซอร์ไปที่ `http://localhost:5173/` โดยอัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal
```bash
# ติดตั้ง dependencies (หากยังไม่ได้ติดตั้ง)
npm install

# รันโหมด Development
npm run dev

# หรือรันโหมด Production Preview
npm run preview
```
เปิดเบราว์เซอร์และเข้าไปที่ **`http://localhost:5173/`**
